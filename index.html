Pre-LLM Next-Word Prediction

Old n-gram models guess the next word from raw frequency alone, which is very often wrong. Write a passage below with one or more blanks marked <blank> to see how the holes are filled (i.e., predicted) with various models.


The final model <BERT> is small, but shows how far LLMs have come.

Set up the passage

The n-gram models (unigram/bigram/trigram/4-gram) are queried live against infini-gram, a public, no-key API that holds a real, complete index over Dolma v1.7 (2.6 trillion tokens of web pages, books, Wikipedia, Reddit, and code). Every prediction is an exact real count from that corpus — nothing is trained locally, nothing is stored in this repo, and your own story text is never blended in. If an exact-length context was never seen in the corpus, the model backs off to a shorter context exactly the way real n-gram models are supposed to (and the results table tells you plainly when that happened).

Pick models to compare

Two eras of the same task, on the same blank: unigram → bigram → trigram → 4-gram (frequency tables, 1980s–2000s, computed here from exact real counts over a 2.6-trillion-token corpus via infini-gram) → LLM (a real pretrained transformer using full bidirectional context, 2018–present). The n-gram side has no notion of meaning, rhyme, or reference — it only ever matches literal strings of words it has actually seen before, which is exactly why it's "very often wrong" even when the underlying counts are real and enormous.

The LLM option downloads a ~65 MB model the first time (cached after that) and runs it fully in your browser — no server, no API key. The n-gram queries also need internet access (to reach the public infini-gram API) but download nothing to your machine.

N-grams (unigram, bigram, trigram, 4-gram) are answered live by infini-gram, a free public API (no key required) indexing Dolma v1.7 — 2.6 trillion real tokens of web text, books, Wikipedia, Reddit, and code, published as the Hugging Face dataset allenai/dolma. Every number shown is an exact count from that corpus, not a locally-trained approximation and not a simulated sample. No text is stored in or shipped with this repo, and nothing you type is ever mixed into the n-gram predictions — they reflect the real corpus alone. See Liu, Min, Zettlemoyer, Choi & Hajishirzi (2024), "Infini-gram: Scaling Unbounded n-gram Language Models to a Trillion Tokens."
